# PostgreSQL Database Inventory Tool

A shell script that connects to multiple PostgreSQL servers, lists all databases on each, and generates a clean Markdown report — sorted alphabetically by server name.

## Features

- Scans multiple PostgreSQL servers in one run
- Output sorted alphabetically by server name
- Generates a Markdown report with database name, owner, encoding, collation, size, and connection status
- Handles connection failures gracefully — failed servers are noted in the report, script continues
- Works globally for any user with `.pgpass` configured
- Configurable via `servers.conf` — no need to edit the script

## Requirements

- `psql` (PostgreSQL client) installed on the machine running the script
- `~/.pgpass` configured for passwordless authentication

## Setup

### 1. Configure `~/.pgpass`

Add one line per server:

```
hostname:port:*:username:password
```

Then secure it:

```bash
chmod 600 ~/.pgpass
```

### 2. Edit `servers.conf`

Add your PostgreSQL servers (one per line):

```
# Format: hostname[:port]  [username]
db1.example.com
db2.example.com:5432    postgres
db3.example.com:5433    app_user
```

### 3. Make the script executable

```bash
chmod +x pg_list_databases.sh
```

## Usage

```bash
# Basic — uses servers.conf in same directory, writes pg_databases_report.md
./pg_list_databases.sh

# Custom output file
./pg_list_databases.sh --output /tmp/report.md

# Custom config file
./pg_list_databases.sh --config /etc/pg_servers.conf

# Both
./pg_list_databases.sh --config /etc/pg_servers.conf --output /var/reports/pg.md
```
